subject 归一化摘要

根据区域港务局最新发布的2026年第三季度规划草案，东南亚多个主要枢纽港口（包括新加坡港、巴生港及林查班港）已连续两个季度上调其针对码头自动化设备的资本开支预算。本轮预算追加的核心聚焦于无人驾驶水平运输系统（AGV）的采购以及基于AI的智能调度系统升级，总体预算环比增长约15%。

该动向表明，面对持续增长的冷链物流需求及劳动力成本上升压力，该区域的港口运营商正加速推进全面自动化转型。这一资本开支的增加预期将直接带动相关自动化设备供应商及系统集成商的订单增长，为相关行业提供短中期的商业机会。
