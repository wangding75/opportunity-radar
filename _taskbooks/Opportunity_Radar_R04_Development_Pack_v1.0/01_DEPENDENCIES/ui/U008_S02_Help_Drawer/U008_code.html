menu_book

术语说明

  • 机会分数 (Opportunity Score) 系统基于预设维度计算的机会潜在价值评分，0-100 分。
  • 置信度 (Confidence) 情报来源和分析逻辑的可靠性评级，分为高、中、低。
  • 证据覆盖 (Evidence Coverage) 当前机会研究结果被有效证据支撑的百分比。
  • 数据新鲜度 (Data Freshness) 距离底层数据源最后一次成功同步的时间间隔。
