# React 数据可视化规范

## 基本语言

- 主序列用品牌蓝；比较序列用中性灰；异常只用红/橙。一个图最多五个系列。
- 坐标与图例文字最小 12px，网格线为弱中性色；颜色之外必须有名称、图例或形状差异。
- 每张图必须有：标题、结论句、时间窗、单位/口径、来源和可访问的原始数据表。
- 环形图只能比较多个部分与整体；单一比例使用数字和文字，不作装饰图。

## 容器

使用 `ChartFrame` 包裹图表。它要求调用方提供结论、时间窗和来源，并可提供原始数据表；任何缺少这些信息的图表只能作为开发中占位，不能发布。

## 状态

- 加载：图表区域使用与最终尺寸一致的 skeleton。
- 空：解释没有数据的筛选或时间原因，并提供调整入口。
- 部分失败：保留可用序列，标明缺失来源和最近成功时间。
- 错误：显示可读原因、请求 ID 与重试动作，不能把零值当作成功数据。
