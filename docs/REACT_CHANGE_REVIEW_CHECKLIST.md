# React 产品化变更评审清单

每个功能 PR 必须随同提交数据库迁移（如适用）、OpenAPI/前端类型、实现、测试和本清单的答案。任意写操作没有服务端回读、失败态或权限说明，不得合并。

## 契约与数据

- [ ] 页面—能力矩阵已更新；每个按钮已标记真实接口、UI-only、只读或禁用。
- [ ] 写请求具备鉴权、服务端 RBAC、审计、幂等和并发策略；冲突返回 409。
- [ ] API 具有稳定错误 envelope，并覆盖 401、403、409、422、429、5xx。
- [ ] 前端不直接使用 mock、数据库整数 ID 或页面内 `fetch`；成功提示来自 mutation 的服务端成功回读。
- [ ] 数据库迁移可前进/回退，敏感配置只保存 secret reference，不写入日志或响应。

## 交互与状态

- [ ] 加载、空、错误、部分数据、失效数据、重试、保存中和失败后恢复状态齐全。
- [ ] 所有详情 URL 使用 public ID，可直接访问、刷新、前进/后退；不存在实体时显示 404。
- [ ] 表单具备字段校验、脏数据离开保护与防重复提交。
- [ ] 新任务、异步运行和外部通知明确区分“已请求/进行中/已完成/失败”。

## 视觉、响应式与可访问性

- [ ] 附 1536px、1280px、1024px、390px 前后截图，页面有一个明确主动作和视觉重心。
- [ ] 正文/按钮/表单至少 14px，图表/辅助文本至少 12px；所有对比度满足 WCAG AA。
- [ ] 1024px 与 390px 无页面级横向滚动；宽表格提供明确横滚容器与可读的替代视图。
- [ ] 使用语义原生控件；键盘操作、焦点可见、dialog 焦点陷阱/返回焦点、ESC、`aria-*` 均可用。
- [ ] 颜色不是传达状态的唯一方式；图表有标题、时间窗、口径、来源和数据替代文本。

## 验证与发布

- [ ] `npm run build`、`npm run test:smoke`、`npm run test:ui-baseline` 与相关后端测试通过。
- [ ] 契约、权限、迁移、失败路径与浏览器测试已新增或更新。
- [ ] bundle、请求数量、LCP/INP、无障碍和视觉差异没有未经说明的退化。
- [ ] 说明 feature flag、灰度范围、监控指标和可验证的回滚路径。
